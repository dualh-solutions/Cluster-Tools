Since iOS 11 (2017), iPhones capture photos in HEIC (High Efficiency Image Container) format by default. HEIC files are significantly smaller than JPG while maintaining superior quality — a deliberate engineering decision by Apple. The problem: HEIC is not universally supported outside Apple's ecosystem.

## What is HEIC/HEIF?

**HEIF** (High Efficiency Image Format) is a container format developed by the MPEG group. **HEIC** is Apple's implementation of HEIF for still images. It uses H.265/HEVC compression technology — the same algorithm used for high-efficiency video — to achieve roughly 50% smaller file sizes than JPG at equivalent or better visual quality.

A standard iPhone photo at HEIC format is typically 3–5MB. The same image in JPG would be 6–10MB. For users who take thousands of photos per year, this storage savings is substantial — which is why Apple made it the default.

## Where HEIC Fails

Despite its technical superiority, HEIC adoption is limited outside Apple devices:

- **Windows 10/11** — requires a paid codec extension from the Microsoft Store to open HEIC natively (or the free HEIF Image Extensions, which only works with certain files).
- **Google Photos / web uploads** — Google Photos accepts HEIC but many other web platforms don't.
- **Social media** — most platforms (Instagram, Facebook, Twitter) accept HEIC from iOS app uploads but reject it from browser/desktop uploads.
- **Photo editing software** — Photoshop supports HEIC in recent versions but older software doesn't.
- **Email / file sharing** — HEIC attachments often fail to preview in non-Apple email clients.

## Tip: Prevent HEIC on Your iPhone

If you want your iPhone to always save photos as JPG, go to **Settings → Camera → Formats** and select **Most Compatible**. This makes your camera save JPGs instead of HEICs. The tradeoff: photos take roughly twice the storage space.

## Frequently Asked Questions

**Is HEIC better quality than JPG?**
Yes, technically. HEIC preserves more visual information at smaller file sizes. When you convert to JPG, you lose some of this advantage — the output is good quality JPG, but not as efficient as the original HEIC.

**Why can't Windows open HEIC files directly?**
HEIC uses the H.265 (HEVC) codec, which has patent licensing requirements. Microsoft charges for the codec rather than bundling it free. Apple licenses it for their platform but not others.

**Can I convert Live Photos (HEIC + video)?**
The converter handles the still HEIC image portion. The motion video component of a Live Photo is a separate `.MOV` file and isn't converted here.

**Is there a file size limit?**
No server-side limit. The HEIF decoder runs in your browser's WebAssembly runtime. Large HEIC files (20MP+, common on iPhone Pro models) may take a few seconds to decode.

**What quality setting should I use?**
90% is a safe default — visually excellent and the file size is still much smaller than the original HEIC. For social media thumbnails or email use, 80% is sufficient.
