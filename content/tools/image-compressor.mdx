## What is Image Compression?

Image compression reduces the file size of a graphic in bytes without degrading the quality of the image to an unacceptable level. The reduction in file size allows more images to be stored in a given amount of disk or memory space. It also reduces the time required for images to be sent over the internet or downloaded from web pages.

### Lossy vs. Lossless Compression
- **Lossy Compression:** (Like JPG) Removes some data from the original image to dramatically reduce file size. You lose some quality, but it's often imperceptible to the human eye.
- **Lossless Compression:** (Like PNG) Compresses the image without losing any data. The file size is reduced, but not as much as lossy compression.

The Pressto Image Compressor primarily uses lossy compression techniques tailored to output incredibly small files while maintaining excellent visual fidelity.
