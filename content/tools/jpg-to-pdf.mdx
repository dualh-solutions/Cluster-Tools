## Turn JPG Images into a PDF — Instantly, Privately

Whether you're submitting scanned documents, combining photos for a portfolio, or packaging multiple screenshots into one shareable file, converting JPG images to PDF is one of the most common document tasks people do every day.

Cluster Tools handles this entirely in your browser using [jsPDF](https://github.com/parallax/jsPDF), a lightweight JavaScript library. Your images are never uploaded to a server — they're read directly from your device, placed on virtual pages, and packed into a PDF binary in your browser's memory. The final download goes straight to your device.

## What Actually Happens When You Convert

Each JPG you add is decoded and drawn onto a page in a new PDF document. Cluster Tools preserves the original aspect ratio of each image — no stretching or cropping — and scales the image to fill the page while respecting standard A4 or Letter dimensions. If you drag in a landscape photo, the page orientation automatically adjusts.

For multi-image PDFs, each image occupies exactly one page in the order you arranged them. You can drag and reorder images before generating the PDF.

## Frequently Asked Questions

**What image formats can I combine into a PDF?**
Cluster Tools supports JPG, JPEG, PNG, and WebP files. Internally, all images are rasterized to a compatible format before being embedded in the PDF.

**Is there a limit on how many images I can add?**
No hard limit. Practically, very large images (4000×3000px, 5MB each) will use significant browser memory. You can typically handle 50–100 high-resolution images before running into browser memory constraints.

**Will the image quality be preserved?**
Yes. Images are embedded in the PDF at their original resolution — no recompression happens unless you explicitly choose to reduce file size. The PDF will be proportionally larger for higher-resolution images.

**Can I control the page size (A4 vs. Letter)?**
Yes. You can choose between common page sizes. By default, Cluster Tools fits each image to A4 dimensions at 72 DPI equivalency, which is standard for digital PDFs.

**Can I later edit the PDF or extract the images back?**
The images are embedded as raster data in the PDF. You can extract them using a tool like [PDF to JPG](/tools/pdf/pdf-to-jpg) or Adobe Reader's "Save as Image" feature.
